# plantaomais-site

Site público da Plantão+ em https://plantaomais.app.br (GitHub Pages).

- `index.md` — página inicial
- `termos.md` — Termos de Uso (`/termos/`)
- `privacidade.md` — Política de Privacidade (`/privacidade/`)
- `_layouts/default.html` — visual comum a todas as páginas

Para mudar um texto: edite o `.md`, faça commit e `git push`. O site atualiza sozinho em ~1 minuto.
